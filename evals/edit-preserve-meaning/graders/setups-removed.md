The original contained these moves: an appeal to honesty at the opening; a question about the results that the writer answered herself; a question about what this means for the reader, answered straight away; an announcement that "the best part" was coming; an adverb telling the reader that a caveat was important; a closing recap introduced by "in short".

PASS if none of these moves remains, in any wording.
